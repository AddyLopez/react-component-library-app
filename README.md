# React Component Library App

View Project: [https://react-component-library-app.netlify.app/](https://react-component-library-app.netlify.app/)

## Description

This application is a UI component library coded in React with Tailwind CSS styling. It features a sidebar component with custom navigation links to the following UI components: dropdown, accordion, buttons, modal, table (sortable), and counter. The purpose was to gain experience exploring the hidden complexities and unique challenges behind building truly reusable components that just about every React project will need.

It afforded lots of practice in granular detail with all the ins and outs of React, including: state design and management, data sharing, props, events, hooks and custom hooks, cleanup functions, context provider, portals, reducers, forms, custom routing, refactoring to support maximal reusability, utility styling, React Icons, sorting, and more. (The learning emphasis was on implementation and generic styling, so there is some placeholder content of no import.)
